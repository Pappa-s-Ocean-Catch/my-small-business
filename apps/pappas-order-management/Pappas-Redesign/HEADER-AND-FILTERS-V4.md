# Compact app header and collapsible order filters

- Shared header: 56 logical units, one-line page name, uniform 20-unit stroke icons in 40-unit visual buttons (native 48-unit hit regions).
- Remove the shop-name eyebrow, normal register text and oversized avatar/actions.
- POS Groups / Quick List share the header. No separate stepper or Quick List row. Selected group/product is identified compactly in content.
- Search stays on demand, behind the magnifier. Tapping a product still adds immediately; level 3 updates that same line.
- Live / On the way / Completed remain frequent tabs. Pre-orders is conditional as before.
- Order filters are collapsed by default. Header icon opens/closes them; hiding retains selected values and shows an active-count badge.
- Source 001: collapsed filters. Source 002: expanded filters. Source 013: configurable layout editor. P02: conditional fourth order tab.

Small tablet checks target 1024 × 768 and 1280 × 800, plus 768 × 1024 portrait and 390 × 844 phone. Main content starts directly beneath the compact chrome. The saved layout determines tile appearance and responsive columns.
